## ✍️ Añadir una publicación

1. Duplica la [plantilla de ficha](plantillas/articulo.md) en `articulos/`.
2. Nombra el archivo como `AAAA-MM-DD-tema.md`, usando la fecha publicada en el blog.
3. Completa título, enlace, resumen y temas.
4. Añade una fila al índice, de más reciente a más antigua.
